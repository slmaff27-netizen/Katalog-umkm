# Katalog UMKM Sekar Jagad Solo
Katalog produk dinamis berbasis PHP (Pertemuan 7 Pemrograman Web).
## Cara menjalankan
1. Salin folder ini ke htdocs/ (XAMPP) atau www/ (Laragon).
2. Nyalakan Apache.
3. Buka http://localhost/katalog-umkm/
## Fitur
- Kartu produk dirender dengan foreach
- Label stok dengan match(true)
- Filter kategori lewat URL
